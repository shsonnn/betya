# 오늘의 벌칙은?

친구들이 차례로 2D 주사위 두 개를 굴리고, 두 눈의 합에서 끝자리 숫자가 가장 작은 사람이 벌칙에 당첨되는 정적 프론트엔드 게임입니다.

- 2~12명 인원 조절
- 참가자 이름 직접 입력
- 주사위 점 배열이 슬롯머신처럼 세로로 흐르는 1.8초 애니메이션
- 가능한 동안 끝자리 결과가 서로 겹치지 않도록 선택
- 끝자리 `0`은 한 게임에서 최대 한 번만 등장
- 백엔드와 빌드 과정 없이 정적 호스팅 가능

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. 별도 설치, 빌드, 백엔드가 필요하지 않습니다.

Cloudflare Pages에 올릴 때는 `index.html`, `style.css`, `script.js`가 배포 루트에 오도록 업로드합니다.

## 규칙

1. 인원수를 정하고 참가자 카드의 이름을 수정합니다.
2. 정한 순서대로 버튼을 한 번씩 누릅니다.
3. 버튼을 누르면 주사위 두 개가 동시에 굴러갑니다.
4. 두 눈의 합에서 끝자리 숫자만 비교합니다.
5. 끝자리 숫자가 가장 작은 사람이 벌칙에 당첨됩니다.
6. 10개 끝자리를 모두 사용해 중복이 불가피한 경우 가장 적게 나온 끝자리를 우선합니다.
