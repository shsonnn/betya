# 오늘의 벌칙은?

친구들이 차례로 주사위 두 개를 굴리고, 두 눈의 합에서 끝자리 숫자가 가장 작은 사람이 벌칙에 당첨되는 프론트엔드 게임입니다. 2~12명 사이에서 인원수를 조절하고 참가자 이름을 직접 수정할 수 있습니다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. 별도 설치나 백엔드가 필요하지 않습니다.

## 규칙

1. 인원수를 정하고 참가자 카드의 이름을 수정합니다.
2. 정한 순서대로 버튼을 한 번씩 누릅니다.
3. 버튼을 누르면 주사위 두 개가 동시에 굴러갑니다.
4. 두 눈의 합에서 끝자리 숫자만 비교합니다.
5. 끝자리 숫자가 가장 작은 사람이 벌칙에 당첨됩니다.
6. 가장 작은 숫자가 같은 경우 공동 벌칙입니다.
